## 需求与范围

- 关联需求：FR-AUTH-001～005、FR-ADM-001；US-004～006；AC-US-004～006、AC-NFR-003～004 中的账号与角色部分。
- 用户目标：创建普通账号、登录、刷新后恢复会话、安全退出；管理员使用预置账号登录。
- 本次实现：初始化 Vue/FastAPI 工程，账号/会话 PostgreSQL 迁移，注册和登录页面、角色守卫、Cookie/Origin/CSRF、管理员初始化与自动化验证。
