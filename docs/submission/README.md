# 作业提交清单

当前为准备阶段，以下均待对应功能开发后核对。

- [ ] 完成一个明确的真实 Feature，并能演示其行为。
- [ ] 功能与测试代码已提交，记录对应 Commit ID。
- [ ] 为该 Feature 添加有意义的测试。
- [ ] 保存真实的测试通过记录，并说明运行环境和对应版本。
- [ ] 完成 Agent Development Log，体现团队决策、Agent 操作与反馈。
- [ ] 绘制一次真实典型开发过程的 Trajectory。
- [ ] 整理功能验收证据，说明已知限制。

`demo/` 存放功能截图、演示提纲或演示材料；测试证据统一存放在 `docs/testing/` 并在此引用。教师未指定的材料格式可根据团队习惯调整。
