# F001 演示步骤

先按两端 README 安装依赖，设置自己的 `backend/.env`，执行迁移；需要演示管理员时由种子命令创建自己的管理账号。不要将当前本机 `.env` 或实际口令作为附件。

演示地址：默认 `http://localhost:8000/#/register`（先构建前端再运行后端）。可用项目根目录 `scripts/start.py`，也可按后端 README 的命令启动。

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 注册页输入合法用户名和密码，确认密码留空提交 | 在确认密码附近提示，不发送注册请求 |
| 2 | 确认密码输入不同内容提交，再修正为相同值 | 不同内容被阻止，完全一致后注册成功，转登录页 |
| 3 | 先用错误密码登录，再输入刚设置的正确密码 | 统一提示用户名或密码错误；正确密码进入普通用户账号页 |
| 4 | 刷新页面 | 从服务器恢复当前用户身份 |
| 5 | 普通用户访问 `/#/admin` | 提示无权访问 |
| 6 | 退出，再访问 `/#/account` | 返回登录页；原会话不能继续访问 |
| 7 | 用本机自行初始化的管理员账号登录 | 进入管理员身份入口，明确其他管理业务待开发 |

测试证据可直接展示最终 71/26/20 项通过结果、真实开发日志和 Trajectory PNG。不要把管理员身份入口演示为已完成景点、预约或评价管理。

参与情况：只有用户本人参与；用户决定范围并提供反馈，Codex 完成实现、测试与材料整理。没有多人分工或团队评审证据。
